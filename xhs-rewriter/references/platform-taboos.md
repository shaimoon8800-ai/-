# 平台禁忌词与合规清单

> 本清单用于**自查**。以下是"不能写"的表述，不是"建议写"的表述。

## 一、导流类（最容易限流）

| 禁止 | 变形写法也别用 |
|---|---|
| 留联系方式 | 微信号、手机号、邮箱写在正文或图里 |
| 引导平台外沟通 | "看我主页简介""评论区第一条" |
| 暗示私下联系 | "懂的都懂""扣 1" |
| 二维码 | 图片里出现任何二维码 |
| 其他平台名 | 直接提站外平台名称做搬家引导 |

**注意**：图片里的文字、水印、评论区，都会被审核。把联系方式藏在图里同样违规。

## 二、绝对化用语（广告法风险）

| 禁止 | 可用替代 |
|---|---|
| 最有效 / 最好 / 最强 | 我试过最合适的 / 适合我的 |
| 第一 / 全网第一 | 我认为比较好的 |
| 永久 / 彻底根治 | 长期 / 改善 |
| 100% 有效 | 对我有效 / 效果因人而异 |
| 国家级 / 顶级 | （删除，无法证明的资质表述） |

## 三、医疗与功效类（高危）

| 禁止 | 说明 |
|---|---|
| 治疗 / 治愈 / 消炎 | 非医疗账号使用即高危 |
| 祛痘 / 祛斑 / 美白（功效承诺式） | 化妆品可描述"使用感受"，不可承诺功效 |
| 减肥 / 瘦身（承诺数字） | "7 天瘦 5 斤"类表述违规 |
| 药到病除 / 根治 | 绝对禁止 |

**安全写法**：描述个人使用感受（"我用着挺舒服"），不承诺效果。

## 四、虚假与诱导类

| 禁止 | 说明 |
|---|---|
| 假抽奖、假限量 | 平台会核查 |
| 硬性诱导互动 | "点赞过百就更新" |
| 数据造假 | 编造销量、评价、案例 |
| 虚假身份 | 冒充专业人士（医生/律师/教师） |

## 五、行业专项注意

| 行业 | 额外要求 |
|---|---|
| 医疗健康 | 需资质；不可诊断、不可荐药 |
| 金融理财 | 不可荐股、不可承诺收益 |
| 教育培训 | 不可承诺"包过""保分" |
| 食品 | 不可宣称保健功能 |
| 母婴 | 涉及儿童安全需谨慎 |
| 房产 | 不可承诺升值 |

## 六、版权与隐私

| 项 | 要求 |
|---|---|
| 图片 | 用自己拍的或用有授权的素材 |
| 音乐 | 用平台曲库 |
| 他人肖像 | 需本人同意 |
| 聊天记录截图 | 需打码昵称与头像 |
| 他人笔记 | 不可搬运，可借鉴结构但内容要原创 |

## 七、自查清单（发布前逐项过）

- [ ] 正文和图片里没有任何联系方式
- [ ] 没有"最""第一""永久""根治"类绝对化表述
- [ ] 没有承诺具体效果的数字（瘦几斤、几天见效）
- [ ] 没有硬性诱导互动的话术
- [ ] 用的是自己拍的照片或有授权的素材
- [ ] 涉及产品体验的，是我真实用过的
- [ ] 特殊行业（医疗/金融/教育）已确认资质要求

## 八、关于"平台规则会变"

各平台的审核标准会调整，本清单是通用底线，不是全部。**发布前用平台自带的合规检测工具再跑一遍**（如内容安全检测入口），有疑问先小号试发。
