# 标签组合策略

## 标签的三层结构

一条笔记的标签建议 **4-6 个**，按三层搭配：

| 层级 | 数量 | 作用 | 举例（以"职场简历"为例） |
|---|---|---|---|
| 大词 | 1 个 | 进入大流量池 | #职场 |
| 精准词 | 2-3 个 | 匹配目标人群 | #简历优化 #求职 |
| 长尾词 | 1-2 个 | 竞争小、转化高 | #应届生求职 #转行 |

**为什么不能全用大词**：大词池子里笔记太多，新号很难被看到。长尾词才是新号的立足点。

## 标签选择方法

### 1. 从内容里找
把笔记里的**核心名词**列出来，直接做标签：
- 提到"简历""JD""面试" → `#简历` `#面试技巧`

### 2. 从人群里找
目标读者会搜什么：
- 应届生 → `#应届生` `#秋招`
- 宝妈 → `#宝妈日常`

### 3. 从场景里找
- `#通勤穿搭` `#租房改造` `#办公室零食`

### 4. 观察同类爆款
看同赛道爆款笔记用了什么标签（**看结构，不抄内容**）。

## 常见错误

| 错误 | 问题 |
|---|---|
| 只打大词 | `#生活 #日常 #分享` —— 泛到没有指向性 |
| 打不相关的热门词 | 蹭流量会被判作弊，且引来不精准人群，反而拉低互动率 |
| 超过 10 个 | 标签过载，权重被稀释 |
| 用生僻词 | 没人搜的词等于没有 |
| 每条笔记都用同一套 | 平台会判定内容同质 |

## 品牌号 vs 个人号

| | 个人号 | 品牌号 |
|---|---|---|
| 大词比例 | 少（1 个） | 可多（1-2 个） |
| 长尾词 | 重点（2-3 个） | 1 个 |
| 品牌词 | 可选 | 建议固定带 1 个 |
| 语气 | 像个真人 | 专业但不说教 |

## 标签的位置

- **正文末尾**（最常用）：不影响阅读，也能被收录
- **正文中间**：容易打断阅读，不推荐
- **首行**：占用了宝贵的"展开前两行"，浪费

## 标签的效果跟踪

发布后看数据：

| 现象 | 可能原因 | 调整 |
|---|---|---|
| 曝光高但互动低 | 标签太泛，人群不精准 | 减少大词，增加长尾词 |
| 曝光低 | 标签太小众或违规 | 加 1 个大词，检查是否命中违禁 |
| 收藏高、点赞低 | 内容有实用价值但缺情绪 | 优化钩子与互动引导 |

## 一组可直接套用的组合模板

### 知识分享类
```
#知识分享  #XX 技巧  #XX 教程  #干货分享  #自我提升
```

### 好物推荐类
```
#好物分享  #XX 推荐  #种草  #居家好物  #平价好物
```

### 经验避坑类
```
#避坑指南  #XX 经验  #踩坑  #新手必看  #真实分享
```

### 教程步骤类
```
#教程  #手把手教学  #XX 怎么做  #保姆级教程  #新手友好
```

> 模板只是骨架，**必须替换成你内容里真实存在的词**。套模板不改词，等于没打标签。
