# 标题公式库（含 20 字约束技巧）

## 硬约束：≤20 字

小红书标题超过 20 字会被截断（后面看不到）。**写完必须数字数**，用 `scripts/xhs_check.py` 校验。

### 怎么在 20 字内塞进信息量

| 技巧 | 做法 | 示例 |
|---|---|---|
| 去掉形容词 | "非常非常好用的杯子" → "这个杯子我买了三个" | 12 字 |
| 用数字代替描述 | "用了很久" → "用了一年" | — |
| 省略主语 | "我用了这个方法" → "这方法真的有用" | — |
| 标点去掉 | 结尾不加句号 | 省 1 字 |
| 符号代字 | 用「」或 ·　代替"的" | 慎用，过度显廉价 |

## 五大流派公式

### 1. 数字清单型

```
X 个方法，让我 XX 从 A 到 B
X 天 / X 周 / X 个月，我 XX 了
我试了 X 个，只留下 1 个
花了 X 块，解决了 X 的麻烦
```

示例：
- `3 个技巧，让我做表快一倍`（13 字）
- `试了 8 个保温杯，只留一个`（13 字）

### 2. 身份共鸣型

```
XX 人真的可以试试这个
只有 XX 才懂
做 XX 的姐妹看过来
XX 党注意了
```

示例：
- `租房党真的需要这个`（10 字）
- `干销售的都懂这种累`（10 字）

### 3. 反常识型

```
别再 XX 了
我劝你别 XX
XX 不是越 X 越好
你以为的 XX，其实 XX
```

示例：
- `别再熬夜背单词了`（8 字）
- `你以为的省钱其实更贵`（11 字）

### 4. 结果对比型

```
坚持 XX 天，我的 XX 变了
从 A 到 B，我只做了这一件事
以前 XX，现在 XX
```

示例：
- `坚持 30 天，皮肤真的变了`（12 字）
- `以前乱糟糟，现在很清爽`（11 字）

### 5. 悬念留白型

```
同事问我最近怎么不一样了
早知道就早点做了
这个方法我藏了很久
```

示例：
- `同事问我最近怎么不一样`（11 字）
- `早知道我早点开始就好了`（11 字）

## 组合技巧：主标题 + 补充

如果 20 字装不下，用**正文第一行**补充：

```
标题：3 个技巧让做表快一倍
正文第一行：从加班到十点到现在六点下班
```

标题负责"抓住"，正文前两行负责"说服"。

## 标题自检四问

1. **20 字内**吗？
2. 有**具体信息**吗？（数字、场景、结果）
3. 目标读者看到会**觉得跟自己有关**吗？
4. 承诺的内容**正文能兑现**吗？

## 五个常见错误

| 错误 | 问题 |
|---|---|
| 写成说明书 | "XX 产品的三大优势" —— 没人点 |
| 全是形容词 | "超好用的神仙单品" —— 空洞 |
| 标题党 | 标题说减肥，内容讲省钱 —— 掉粉 |
| 堆关键词 | "护肤 美白 保湿 抗老" —— 像广告 |
| 太长 | 超过 20 字直接被截，后面白写 |
