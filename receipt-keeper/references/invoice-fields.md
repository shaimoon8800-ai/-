# 发票字段规范与提取规则

## 标准字段清单

| 字段 | 说明 | 是否必填 | 提取方式 |
|---|---|---|---|
| `file` | 来源文件名 | ✅ | 系统 |
| `invoice_no` | 发票号码 | ✅ | 文本正则 |
| `invoice_code` | 发票代码（旧版纸票有，全电发票无） | ⬜ | 文本正则 |
| `date` | 开票日期 | ✅ | 文本正则 |
| `amount` | 价税合计（小写） | ✅ | 文本正则 |
| `tax` | 税额 | ⬜ | 文本正则 |
| `seller` | 销售方名称 | ⬜ | 文本正则 |
| `buyer` | 购买方名称 | ⬜ | 文本正则 |
| `tax_id` | 纳税人识别号 | ⬜ | 文本正则 |
| `type` | 票种 | ⬜ | 关键词匹配 |
| `category` | 费用类别 | ⬜ | 按销售方/品名推断 |
| `status` | 状态（有效/重复/待补录） | ✅ | 系统 |

## 票种识别关键词

| 票种 | 识别关键词 |
|---|---|
| 增值税电子专用发票 | `增值税电子专用发票` / `电子专票` |
| 增值税电子普通发票 | `增值税电子普通发票` / `电子普票` |
| 增值税专用发票（纸质） | `增值税专用发票`（无"电子"字样） |
| 增值税普通发票（纸质） | `增值税普通发票` |
| 电子发票（全电） | `电子发票（普通发票）` / `电子发票（增值税专用发票）` |
| 航空运输电子客票行程单 | `航空运输电子客票行程单` |
| 铁路电子客票 | `铁路电子客票` / `中国铁路` |
| 出租车票 | `出租汽车` / `出租车` |
| 定额发票 | `定额发票` |
| 收据 | `收据`（非税务发票，注意报销限制） |

## 各字段的常见写法（正则要覆盖）

### 发票号码
```
发票号码：12345678
发票号码:12345678
No.12345678
全电发票为 20 位：发票号码：24312000000012345678
```
> 全电发票的 20 位号码中包含开票日期信息（第 3-6 位为年月日相关），可交叉验证。

### 开票日期
```
2026年10月13日
2026-10-13
2026/10/13
开票日期：2026年10月13日
```

### 金额（价税合计）
```
价税合计（大写）肆仟贰佰捌拾陆圆伍角整　（小写）¥4286.50
合计金额：￥1,234.56
金额 ¥88.00
```
**优先取"（小写）"后的数字**，大写金额用于交叉校验。

### 销售方 / 购买方
```
销售方名称：某某科技有限公司
销方名称：某某科技有限公司
购买方名称：某某商贸有限公司
```
注意区分：**开票方（销售方）才是"谁开的票"**，报销时通常按销售方判断类别。

### 纳税人识别号
```
纳税人识别号：91110000MA01AB2C3D
统一社会信用代码：91110000MA01AB2C3D
```
长度：15 / 18 / 20 位，含数字与大写字母。

## 费用类别推断规则

| 销售方/品名含 | 类别 |
|---|---|
| 铁路 / 航空 / 出租车 / 网约车 / 地铁 / 客运 | 交通 |
| 酒店 / 宾馆 / 民宿 / 住宿 | 住宿 |
| 餐饮 / 餐厅 / 食品 / 咖啡 | 餐饮 |
| 办公 / 文具 / 打印 / 耗材 | 办公 |
| 加油 / 停车 / 过路 | 车辆 |
| 通信 / 电信 / 移动 / 联通 | 通讯 |
| 会务 / 展览 / 培训 | 会务培训 |
| 其他 | 其他 |

**推断不确定时归入「其他」并标注，不硬分类。**

## 提取失败的处置

| 情况 | 处置 |
|---|---|
| PDF 无文本层（扫描件） | 标记 `待人工补录`，输出补录模板 |
| 字段缺失（如无发票号） | 留空 + 警告，**不用其他字段凑** |
| 正则命中多个候选 | 取最可信的（优先带字段名前缀的），记录全部候选到警告 |
| 金额出现多个 | 取"价税合计"，并在警告中列出所有候选金额 |
