# 转写稿清洗规则

## 清洗的目标
把"说话的原始流"变成"能读的文本"。**只去噪，不改写**——任何观点、结论、数字都必须保留原样。

## 五类噪声与处置

### 1. 口水词（删除）
`嗯` `啊` `那个` `就是说` `对对对` `这个这个` `然后然后` `你知道吧`
处理：直接删。连续出现只删到剩 1 个（保留语气节奏）。

### 2. 重复表达（合并）
```
原始：我觉得这个方案可以，就是我觉得这个方案应该可以
清洗：我认为这个方案可行
```
**注意**：合并时不能改变语义强度。"应该可以" ≠ "可以"，宁可保留原话。

### 3. 打断与重叠（标注）
```
原始：A：那我们下周—— B：下周我来同步  A：行
清洗：A：那我们下周…（被 B 打断）  B：下周我来同步。A：同意。
```

### 4. 同音字/转写错误（修正）
常见错转：

| 错转 | 正确 |
|---|---|
| 上家 / 商架 | 上架 |
| 开屁爱 / K P I | KPI |
| 复盘 / 富盘 | 复盘 |
| 拉新 / 拉心 | 拉新 |
| 增长 / 赠长 | 增长 |
| 转化率 / 转花率 | 转化率 |
| 私域 / 思域 | 私域 |

**修正前提**：结合上下文能 100% 确定。不确定就保留原样并加 `[?]` 标记。

### 5. 无信息量段落（折叠）
超过 30 秒的纯闲聊、寒暄、设备调试、等人：
```
（此处省略约 3 分钟：会前寒暄与设备调试）
```

## 发言人标注

**有标注的**：保留原名（如"张三：…"）。

**无标注的**：按语义推断角色，标注为：
- `发言方 A`（通常是主持人/发起人——提问最多、做总结的人）
- `发言方 B`、`发言方 C`（按首次发言顺序）

推断线索：谁在分配任务、谁在汇报进度、谁在提反对意见。

## 时间戳处理

- 有精确时间戳 → 保留，格式 `[00:12:35]`
- 无时间戳 → 按段落编号 `[段 1]`
- 纪要正文里不要出现时间戳，只在**关键决议**后标注来源位置，如"（依据：段 12）"，便于回溯

## 清洗后的自检

- [ ] 有没有把"可能"洗成"确定"？
- [ ] 有没有把"某个人的意见"洗成"大家的共识"？
- [ ] 数字、金额、日期是否与原文逐字核对过？
- [ ] 删除的比例是否超过 40%？（超了说明删过头，可能在删观点）
- [ ] 剩下的文本，没参会的人能读懂吗？
