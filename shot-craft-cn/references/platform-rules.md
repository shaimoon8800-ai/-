# 各平台节奏规则与审核红线

## 平台节奏对照

| 平台 | 黄金时长 | 钩子窗口 | 完播基准 | 节奏特点 |
|---|---|---|---|---|
| 抖音 | 21-45s | 前 3s | 30%+ | 快切，3-5 秒一个信息点 |
| 视频号 | 60-90s | 前 5s | 20%+ | 慢一些，重情绪与观点 |
| 小红书 | 30-60s | 前 3s | 25%+ | 真实感，画面质感优先 |
| B 站 | 3-8min | 前 15s | — | 信息密度优先，可长 |
| 快手 | 30-60s | 前 3s | — | 接地气，强互动 |

> 完播基准为经验参考，不同赛道差异大，仅用于判断"是否偏离常识"。

## 抖音

**推荐**：强钩子、快节奏、字幕常驻、BGM 抓耳
**避免**：开场自我介绍、超过 5 秒的铺垫、画面静止超过 8 秒
**审核注意**：
- 不能出现其他平台的水印或 logo
- 带货需明示商业属性
- 医疗、金融、教育类需资质

## 视频号

**推荐**：观点鲜明、有温度、适合转发（中老年用户占比高）
**避免**：过度网感化的梗、快剪、纯搞笑无信息
**审核注意**：
- 与微信生态规则一致，跨平台导流管控极严
- 诱导分享、集赞类文案会被限流

## 小红书

**推荐**：真实体验、画面干净、首图即封面（必须设计）
**避免**：硬广口气、"最好的""第一"等绝对化用语、评论区留联系方式
**审核注意**：
- 绝对化用语触发广告法风险
- 医疗功效词（祛痘、瘦身、治疗）高危
- 引导到其他平台会限流甚至封号

## B 站

**推荐**：信息密度高、有观点、可长可短但要"值"
**避免**：水时长、纯搬运
**审核注意**：
- 二创需注意版权
- 商业内容需标注

## 通用审核红线（所有平台）

| 类型 | 禁止内容 |
|---|---|
| 违法 | 违法商品、违禁品、赌博、诈骗 |
| 医疗 | 无资质谈诊疗、功效承诺 |
| 金融 | 荐股、保证收益、非法集资 |
| 未成年人 | 涉及未成年人的不当内容 |
| 侵权 | 搬运他人作品、未授权音乐 |
| 虚假 | 假抽奖、假限量、数据造假 |
| 隐私 | 未经同意出现他人肖像与个人信息 |

## 音乐与素材版权

| 来源 | 可用性 |
|---|---|
| 平台内置曲库 | ✅ 安全（在平台内使用） |
| 商用授权音乐站 | ✅ 需购买授权 |
| 热门流行歌 | ⚠️ 平台内可能可用，跨平台分发有风险 |
| 影视片段 | ❌ 高侵权风险 |
| 他人视频素材 | ❌ 除非有授权 |

**建议**：BGM 优先用平台曲库；需要跨平台分发时，用可商用授权的音乐。

## 时长与内容量的换算

中文口播语速约 **240 字/分钟**（正常讲述，不含停顿）。

| 目标时长 | 口播字数上限 |
|---|---|
| 15s | ≈ 60 字 |
| 30s | ≈ 120 字 |
| 60s | ≈ 240 字 |
| 90s | ≈ 360 字 |
| 3min | ≈ 720 字 |

**超了就必须删内容**，不能靠加快语速硬塞——语速一快，完播率必掉。
用 `scripts/shot_duration.py` 做机械校验。
