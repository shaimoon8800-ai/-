# 数据的表达方式

## 一个数字说明不了什么

```
❌ 本月销售额 128 万
✅ 本月销售额 128 万，环比 +12%，达成月度目标 107%
```

**数字必须带参照**，参照有四种：

| 参照 | 说法 | 适用 |
|---|---|---|
| 目标 | 达成率 107% | 有 KPI 的场景 |
| 上期 | 环比 +12% | 看趋势 |
| 同期 | 同比 +8% | 排除季节性 |
| 同类 | 高于团队均值 15% | 看相对位置 |

## 结论先行的三种句式

### 句式 1：结果 → 归因

```
转化率 3.2%，高于目标 0.7 个百分点，主要因为新版落地页上线。
```

### 句式 2：偏差 → 解释

```
GMV 完成 88 万，低于目标 12 万。差距主要来自 3 月 15-20 日的
供应中断（影响约 9 万），其余为自然波动。
```

### 句式 3：对比 → 判断

```
A 渠道获客成本 45 元，B 渠道 78 元。建议下季度把预算向 A 倾斜，
预计同预算下可多获客 30%。
```

## 常见数据表达错误

| 错误 | 问题 | 改法 |
|---|---|---|
| 只有绝对值 | "新增 500 用户" | 加"环比 +18%" |
| 只有百分比 | "增长 20%" | 加基数"从 1000 到 1200" |
| 平均值掩盖分布 | "平均订单 300 元" | 加"中位数 180 元（少数大单拉高均值）" |
| 混淆口径 | "用户数 10 万" | 明确"注册用户/活跃用户/付费用户" |
| 忽略基数 | "提升 300%" | 加"从 1% 到 4%"（小基数大倍数） |
| 时间口径不清 | "本月数据" | 明确"自然月/统计周期/截至日期" |

## 不确定时怎么表述

| 情况 | 写法 |
|---|---|
| 数据未出全 | "截至 X 日，初步数据为…" |
| 归因不确定 | "初步判断主要因为…，仍在验证" |
| 预测 | "按当前节奏预计…（置信度中等）" |
| 无法量化 | "具体影响尚在评估，X 日前给出" |

**不确定就说不确定**——比事后被打脸强。

## 数据的呈现方式

| 场景 | 方式 |
|---|---|
| 单个关键指标 | 大数字 + 对比（KPI 卡） |
| 趋势 | 折线图 |
| 结构占比 | 饼图（≤5 项）/ 堆积柱状图 |
| 对比 | 柱状图（按值排序） |
| 精确数值 | 表格 |
| 达成情况 | 进度条 / 达成率 |

**放在汇报里的图，标题要写成结论**：不写"销售额趋势"，写"3 月销售额环比下降 12%"。

## 给不同对象的表达差异

| 对象 | 关注点 | 表达侧重 |
|---|---|---|
| 直属领导 | 有没有达成目标 | 执行细节 + 数据 |
| 高层 | 战略价值 | 结论 + 关键数字 + 影响 |
| 跨部门 | 对他们有什么影响 | 配合点 + 时间节点 |
| 财务 | 预算与合规 | 金额、口径、凭证 |
| 客户 | 交付质量 | 结果 + 里程碑 |

**同一个成果，给不同人写不同的版本**——这不是圆滑，是沟通效率。

## 汇报里数字的三个纪律

1. **每一个数字都能说出出处**（哪个系统、什么口径、谁在那里）
2. **每个数字都能被追问三层**（怎么算的？为什么是这个数？和谁比？）
3. **不确定的数字宁可空着**（写「暂缺」并说明何时能给）
