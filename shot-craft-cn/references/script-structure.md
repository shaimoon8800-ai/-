# 选题角度与内容结构

## 五个通用选题角度

同一个主题，换个角度就是另一条视频。先给 3 个，让用户挑。

| 角度 | 适用 | 结构 | 示例主题：「便携榨汁杯」 |
|---|---|---|---|
| **痛点直击** | 解决问题类产品 | 痛点场景 → 之前的糟糕做法 → 新做法 → 结果 | "早上没时间吃水果？" |
| **反常识** | 有认知差的领域 | 常见做法 → 为什么错 → 正确做法 → 证据 | "榨汁杯根本不用加满水" |
| **对比测评** | 有竞品的品类 | 对比维度 → 逐项实测 → 结论 | "三款榨汁杯，我只留了一个" |
| **场景代入** | 生活方式类 | 具体场景 → 使用过程 → 感受 | "出差第三天，我在酒店做了杯果汁" |
| **身份呼唤** | 有明确人群 | 点名人群 → 他们的困境 → 方案 | "租房党真的需要这个" |

## 内容结构模板

### 15-30 秒（抖音/小红书）

```
0-3s    钩子（一句话制造停留）
3-8s    问题/背景（共鸣）
8-20s   方法/展示（核心信息，最多 2 个点）
20-28s  结果（可视化的变化）
28-30s  互动（提问或引导）
```

### 60-90 秒（视频号）

```
0-5s    钩子
5-15s   我的故事/身份建立
15-50s  干货主体（3 个点，每点约 10 秒）
50-70s  一个反例或常见误区
70-85s  总结 + 观点
85-90s  互动
```

### 3 分钟以上（B 站/深度内容）

```
0-15s   钩子 + 本期承诺（"看完你能学会 X"）
15-30s  目录（3-4 个部分）
主体    每个部分：结论先行 → 展开 → 举例
结尾    总结 + 下期预告
```

## 单条视频只讲一件事

最常见的失败：15 秒视频塞 5 个卖点。观从记不住任何一条。

**判断标准**：看完这条视频，观众能用一句话复述出来。如果不能，内容太多。

## 钩子与内容的匹配

钩子承诺什么，内容就必须给什么。三种常见的"钩子脱节"：

| 钩子 | 脱节表现 | 后果 |
|---|---|---|
| "三招搞定" | 只讲了一招 | 完播率崩、评论区骂 |
| "我后悔了" | 全程没讲后悔什么 | 被判定标题党 |
| "免费分享" | 结尾要求付费 | 举报 |

## 带货视频的特殊结构

```
0-3s    使用场景（不是产品特写）
3-10s   问题暴露
10-30s  产品介入 + 效果
30-40s  价格锚点（对比或换算）
40-45s  引导（点击/评论区）
```

**注意**：带货内容必须在画面或文案中明示商业属性（如"含推广"），这是合规要求，也是尊重观众。
