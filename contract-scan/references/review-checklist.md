# 审查清单（按合同类型）

## 通用十项（任何合同都先过这十条）

- [ ] **当事人信息**：名称是否与营业执照/身份证一致？有无错别字？
- [ ] **标的**：到底买卖/服务/租赁的是什么？描述是否具体到可识别？
- [ ] **金额与币种**：含税还是不含税？大写小写是否一致？
- [ ] **期限**：起止日期是否明确？起算点是什么（签字日/付款日/交付日）？
- [ ] **付款方式**：分期节点、比例、账户信息是否写清？
- [ ] **交付与验收**：标准、方式、时限、地点
- [ ] **违约责任**：双方对等吗？有无上限？
- [ ] **解除条件**：什么情况下可以解除？解除后果是什么？
- [ ] **争议解决**：管辖地/仲裁机构写明确了吗？
- [ ] **附件与签署**：附件是否齐全？盖的是公章还是财务章？日期填了吗？

## 租房合同

- [ ] 出租方是否有权出租（房产证/委托书）
- [ ] 押金金额、退还条件与时限（"X 个工作日内无息退还"）
- [ ] 租金涨幅条款（是否约定每年涨幅上限）
- [ ] 维修责任划分（家电坏了谁修？自然损耗谁承担？）
- [ ] 提前解约条件与违约金
- [ ] 是否允许转租/养宠物/装修
- [ ] 水电燃气物业费的承担方与结算方式
- [ ] 房屋交付时的状况清单（拍照留存）

## 劳动合同

- [ ] 试用期长度（法定上限：1 年合同≤1 个月，1-3 年≤2 个月，3 年以上≤6 个月）
- [ ] 试用期工资（不得低于转正工资的 80%）
- [ ] 工作岗位与工作地点（是否含糊到可以随便调）
- [ ] 工资构成（基本工资/绩效/补贴比例，影响加班费与社保基数）
- [ ] 加班与调休规则
- [ ] 竞业限制（有无补偿金？标准是多少？）
- [ ] 保密与知识产权条款
- [ ] 解除条件与赔偿
- [ ] 社保公积金缴纳基数与地点

## 采购 / 供货合同

- [ ] 产品规格、型号、数量、单位
- [ ] 质量标准（国标/行标/企标/样封）
- [ ] 验收方式与异议期（"收货后 X 日内提出异议"）
- [ ] 付款节点（预付比例、到货付、验收付、质保金）
- [ ] 交货期与逾期责任
- [ ] 退换货与质量索赔
- [ ] 价格调整机制（原材料波动怎么办）

## 服务 / 外包合同

- [ ] 服务范围与交付物清单（越具体越好）
- [ ] 验收标准与流程
- [ ] 变更流程（需求变更如何计价）
- [ ] 知识产权归属与使用范围
- [ ] 保密条款
- [ ] 终止条件与已完成部分的结算
- [ ] 人员更换与转包限制

## 合作 / 合伙

- [ ] 各方出资方式与金额（含技术、资源如何折算）
- [ ] 利润分配与亏损分担比例
- [ ] 决策机制（谁拍板？哪些事项需一致同意？）
- [ ] 退出机制（退伙、转让、优先购买权）
- [ ] 竞业与关联交易限制
- [ ] 解散与清算方式

## 签署前最后检查

- [ ] 所有空白处都填了吗？（空白处可能被事后填写）
- [ ] 附件都附上了吗？（附件与正文同等效力）
- [ ] 有几份？各方是否都留存？
- [ ] 签字人是否有权限（法定代表人？授权代表？授权书在哪？）
- [ ] 盖章是公章还是业务章？对方是分公司还是总公司？
- [ ] 日期是否填写完整？
- [ ] 有没有"以本合同为准"vs"以附件为准"的矛盾？
- [ ] 拍照/扫描留存了完整版本吗？
