# 风险条款类型库

> 每类给：典型表述、为什么危险、最坏后果、建议方向。
> **信号词命中不等于条款有问题**，需结合立场与上下文判断。

## 一、责任与赔偿

### 无限责任
- **典型表述**："承担一切损失""赔偿由此产生的全部损失""不设赔偿上限"
- **为什么危险**：赔偿金额没有封顶，理论上可以远超合同金额
- **最坏后果**：一个项目赔掉几年利润
- **建议方向**：争取加"赔偿总额不超过合同金额"或"不超过已收取费用"的封顶条款

### 责任不对等
- **典型表述**：一方"承担全部责任"，另一方"不承担任何责任"
- **建议方向**：至少做到对等，或按过错比例分担

## 二、权利与决定权

### 单方决定权
- **典型表述**："甲方有权单方变更""无需另行通知""最终解释权归甲方"
- **为什么危险**：对方可以随时改规则，你没有议价空间
- **建议方向**：改为"需双方书面确认"；或加"变更需提前 X 日通知，不同意可解除"

### 单方解除权
- **典型表述**："甲方有权随时解除本合同，无需承担任何责任"
- **最坏后果**：你备了货、招了人、投了钱，对方一句话终止
- **建议方向**：争取"需提前 X 日通知"+"已发生的成本应予补偿"

## 三、时间与续约

### 自动续期
- **典型表述**："期满前未提出异议，视为自动续约一年"
- **最坏后果**：忘了提异议，被绑定一年；尤其是服务费、房租、会员类
- **建议方向**：改为到期自动终止，或要求提前提醒义务

### 付款周期过长
- **典型表述**："验收合格后 90 日内付款"
- **最坏后果**：现金流被拖住，还可能无限期验收
- **建议方向**：压缩到 30 日内，并约定"逾期未提异议视为验收通过"

## 四、验收与标准

### 验收标准模糊
- **典型表述**："以甲方满意为准""符合甲方要求"
- **为什么危险**：主观标准 = 对方说了算
- **建议方向**：改为可量化标准（功能清单、指标数值、样张确认）

### 隐形验收条件
- **典型表述**："需经第三方检测合格""需通过甲方内部评审"
- **建议方向**：约定检测机构、时限，以及逾期未完成的默认通过

## 五、知识产权

### 成果归属不清
- **典型表述**：只写"知识产权归甲方所有"，未提署名权、使用权范围
- **注意**：委托创作、软件开发、设计类合同的高频争议点
- **建议方向**：明确"著作权归属 / 使用范围 / 是否可复用于其他项目 / 署名权"

### 无偿永久许可
- **典型表述**："乙方授予甲方永久、无偿、可转授的使用权"
- **最坏后果**：你的成果被对方拿去商业变现，你分不到
- **建议方向**：限定用途、期限、地域；商业使用另行付费

## 六、约束与限制

### 竞业限制
- **典型表述**："离职后 X 年内不得从事同业"
- **注意**：劳动法下竞业限制需**支付补偿金**，无补偿的竞业条款效力存疑
- **建议方向**：确认补偿标准与支付方式；范围与地域要合理

### 保密义务不对等
- **典型表述**：只约束一方保密，另一方无义务
- **建议方向**：双向保密；明确保密期限与例外（已公开信息、法律要求披露）

## 七、押金与保证金

### 无理由不退
- **典型表述**："押金不予退还"（无任何例外情形）
- **建议方向**：约定退还条件、时限与扣减标准（如"扣除实际损失后退还余额"）

### 扣减标准模糊
- **典型表述**："如有损坏，从押金中扣除"（未定义损坏程度与折价方式）
- **建议方向**：约定"自然损耗除外"与折价依据

## 八、争议解决

### 管辖地不利
- **典型表述**："由甲方所在地人民法院管辖"
- **最坏后果**：你在广州，对方在北京，维权成本翻倍
- **建议方向**：争取"被告所在地"或"合同履行地"；或约定仲裁（需明确机构名）

### 放弃救济
- **典型表述**："不得以任何理由主张权利""放弃抗辩权"
- **注意**：部分法定权利不可通过约定放弃，但打官司成本极高
- **建议方向**：争取删除，或限定为"对特定事项的确认"

## 九、分类速查表

| 合同类型 | 最需要盯的条款 |
|---|---|
| 租房 | 押金退还、涨租条件、维修责任、提前解约、转租权 |
| 劳动 | 试用期、竞业、保密、加班与调休、解除条件、绩效扣款 |
| 采购/供货 | 验收标准、付款周期、质量责任、退换货、违约金 |
| 服务/外包 | 交付范围、验收、变更流程、知识产权、终止补偿 |
| 合作/合伙 | 出资与分配、决策机制、退出机制、亏损分担、竞业 |
| 加盟 | 加盟费退还、区域保护、供货义务、经营限制、续约 |
