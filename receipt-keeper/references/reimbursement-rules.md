# 报销单规则与常见退回原因

## 报销单必备信息

| 项 | 说明 |
|---|---|
| 报销人 / 部门 | 与 OA 账号一致 |
| 报销事由 | 具体，不写"日常费用" |
| 费用明细 | 逐条对应台账行 |
| 合计金额 | 与台账合计一致（差一分都会退） |
| 附件张数 | 与票据张数一致 |
| 所属期间 | 如"2026 年 10 月" |
| 审批流 | 按公司规定走 |

## 常见退回原因（提前规避）

### 1. 票据不合规
| 问题 | 说明 |
|---|---|
| 抬头错误 | 必须开公司全称，不能是个人或简称 |
| 税号缺失 | 增值税发票必须有购买方税号 |
| 收据充当发票 | 收据一般不能税前扣除，需确认公司政策 |
| 过期票据 | 多数公司要求当年票据当年报，跨年需特批 |
| 复印件 | 电子发票需提供原件 PDF，不接受截图 |

### 2. 金额问题
- 台账合计 ≠ 票据合计（最常见的退回原因）
- 大写到小写转换错误（¥4286.50 vs 肆仟贰佰捌拾陆圆伍角整）
- 含税额与不含税额混淆
- 重复报销（同一张票报两次）

### 3. 事由问题
- 事由过于笼统："业务招待" → 应写"与 XX 公司洽谈 XX 项目餐费"
- 缺少关联信息：差旅费未注明出差事由与起止日期
- 超标未说明：住宿超标准、商务座未审批

### 4. 附件问题
- 缺行程单（机票需行程单 + 登机牌）
- 会务费缺会议通知或议程
- 团建费缺参与人名单

## 分类标准（按公司通常做法，具体以公司制度为准）

| 科目 | 归集内容 |
|---|---|
| 差旅费 | 交通、住宿、出差餐补 |
| 业务招待费 | 客户餐费、礼品（有扣除限额） |
| 办公费 | 文具、耗材、打印 |
| 通讯费 | 话费、宽带 |
| 会议费 | 场地、会务、培训 |
| 车辆费用 | 油费、过路费、停车费 |
| 福利费 | 员工活动、节日福利 |

**不确定时在备注里标注，让财务定科目——不要自己硬套。**

## 电子台账交付建议

交给财务时，建议同时附上：

1. **xlsx 台账**（本 Skill 产出）
2. **票据文件夹**：按 `日期_金额_销售方.pdf` 重命名，与台账一一对应
3. **异常说明**：重复票、缺票、待补录的清单
4. **一句话摘要**：`X 月共 X 张票，合计 ¥X，其中 X 张待确认`

## 免责说明（必须转达）

本 Skill 只做**整理与辅助核对**，不替代财务审核，也不提供税务建议：

- 票据能否报销、能否税前扣除 → 以公司财务制度与主管税务机关规定为准
- 进项税额能否抵扣 → 由财务/税务专业人士判断
- 涉及跨期、跨主体、大额票据 → 建议提前与财务沟通

## 隐私提醒

台账与票据可能含：
- 个人身份信息（报销人姓名、工号、银行卡号）
- 客户信息（业务招待对象）
- 供应商报价（商业敏感）

**分发前确认知悉范围**，外部传输时建议脱敏。
