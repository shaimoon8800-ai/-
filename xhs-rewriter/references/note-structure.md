# 笔记四段式结构与语感规范

## 四段式

```
【钩子】前 2 行 —— 唯一被展示的部分，决定别人点不点"展开"
【铺垫】我的情况 / 为什么关注这个（建立可信度）
【干货】分点讲清，3-5 点，每点带具体细节
【互动】提问 / 求推荐 / 征集经验
```

### 钩子的写法

前两行在小红书信息流里是唯一可见的，等于"第二标题"。

| 写法 | 示例 |
|---|---|
| 抛出结果 | "用完这个我直接扔了旧的" |
| 制造好奇 | "这个方法我藏了半年" |
| 共鸣痛点 | "是不是每次都整理到崩溃" |
| 反常识 | "原来一直都做错了" |

**不要**："大家好，今天想跟大家分享一下……" —— 这行字被折叠在"展开"后面，等于浪费。

### 铺垫的写法

一句话交代身份与场景，别写履历：

- ✅ "租房第三年，收纳踩过的坑能写一本书"
- ❌ "我是一名有着五年收纳经验的资深整理师"

### 干货的写法

每点格式：**小标题 + 具体做法 + 一个细节**

```
1️⃣ 先分类再收纳
把所有东西倒出来，按"每天用/每周用/几乎不用"分三堆。
几乎不用的那堆，直接装箱塞床底，别纠结。
```

**关键**：给"可执行的动作"，不给"正确的道理"。写"每周日晚花 15 分钟清桌面"，不写"要保持整洁的习惯"。

### 互动的写法

| 类型 | 示例 |
|---|---|
| 提问式 | "你们家是怎么收纳的？评论区教教我" |
| 征集式 | "有更好的方法吗，在线等" |
| 分享式 | "评论区蹲一个同款受害者" |

## 语感规范

### 该有的

| 特征 | 示例 |
|---|---|
| 短句 | "真的有用。用了一个月。"（不用长句） |
| 口语 | "巨好用""谁懂啊""整不会了" |
| 具体 | "398 块""第三周""两平米" |
| 有情绪 | "我服了""绝了""救命" |
| 有停顿感 | 适当换行，一段 1-3 句 |

### 不该有的

| 反例 | 问题 |
|---|---|
| "该产品具有优异的性能" | 说明书口气 |
| "综上所述""因此""由此可见" | 论文口气 |
| "家人们谁懂啊绝绝子YYDS" | 网感过载，显廉价 |
| 每句都加 emoji | 视觉噪音 |
| 大段无换行 | 手机上读不下去 |

## emoji 使用规范

- 每段 0-2 个
- 用作**分段标记**（1️⃣ 2️⃣ 3️⃣）或**情绪点缀**（😭 ✨）
- 不要连续堆叠（"✨✨✨"）
- 不要每一句都加

## 分段与留白

手机屏幕窄，**每段别超过 3 行**。长内容拆成多段，段间空一行。

```
❌ 一大段 200 字不换行

✅ 第一句。
   第二句。
   
   新的一段。
```

## 不同赛道的语感差异

| 赛道 | 语感特征 |
|---|---|
| 美妆 | 细节多、对比强、爱用感叹 |
| 穿搭 | 平实、具体（身高体重、尺码、价格） |
| 母婴 | 真实、克制、避坑导向 |
| 职场 | 理性、有数据、观点鲜明 |
| 家居 | 生活流、场景化、重氛围 |
| 美食 | 感官描写（口感、香味）、步骤清晰 |
| 学习 | 方法论、可执行、有进度感 |

## 长度建议

| 类型 | 字数 | 说明 |
|---|---|---|
| 短笔记 | 100-300 字 | 单点分享、好物推荐 |
| 中长笔记 | 300-600 字 | 教程、清单、经验总结 |
| 长笔记 | 600-1000 字 | 深度攻略（需强结构） |

超过 1000 字建议拆成系列，或做成图片承载信息。

## 写完必做三件事

1. **念一遍**：拗口的地方改掉
2. **在手机上预览**：分段是否合理、emoji 是否过多
3. **数字数**：标题 ≤20 字，正文别超 1000 字
