# 分镜表规范与拍法术语

## 标准分镜表列定义

| 列 | 说明 | 必填 |
|---|---|---|
| 镜号 | 1 起递增；同一拍摄批次的用 1a/1b 标注 | ✅ |
| 时长 | 起止秒数（如 `0-3s`）或单镜时长（如 `3s`） | ✅ |
| 景别 | 特写/近景/中景/全景/远景 | ✅ |
| 画面 | 镜头里**看得见**的内容（谁在做/有什么物件） | ✅ |
| 台词/字幕 | 口播内容或屏幕文字 | ✅ |
| 拍法 | 机位与运动方式 | ✅ |
| 道具/备注 | 需要准备的东西、注意事项 | ⬜ |

## 景别术语

| 景别 | 画面范围 | 常见用途 |
|---|---|---|
| 特写 | 局部（手、脸、产品细节） | 强调细节、情绪放大 |
| 近景 | 胸部以上 | 口播主讲 |
| 中景 | 腰部以上 | 展示动作 |
| 全景 | 全身 + 部分环境 | 展示场景与人物关系 |
| 远景 | 环境为主 | 交代地点、氛围 |

## 拍法术语

| 拍法 | 含义 | 效果 |
|---|---|---|
| 固定机位 | 三脚架/支架不动 | 稳，适合口播 |
| 手持 | 手持拍摄，允许轻微晃动 | 真实感、临场感 |
| 推镜 | 从远到近 | 强调、聚焦 |
| 拉镜 | 从近到远 | 揭示、收尾 |
| 摇镜 | 原地转动 | 展示环境 |
| 跟拍 | 跟随主体移动 | 动态、过程感 |
| 俯拍 | 从上往下 | 展示桌面操作（手作/开箱常用） |
| 第一人称 | 视角即观众视角 | 代入感强 |

## 手机拍摄的实用建议

大部分创作者用手机拍，分镜设计要匹配：

- **光线**：优先靠窗自然光；晚上用环形灯（几十块那种就够）
- **稳定**：手机支架比手稳；没有就靠墙、靠桌
- **收音**：手机自带麦够用，但**离嘴 30cm 内**；嘈杂环境必须用领夹麦
- **构图**：人物不要居中正对，稍微偏一点更自然
- **竖屏**：9:16，人物头部留出上方 1/4 空间

## 纯口播视频的分镜简化

如果真人出镜口播，分镜可以简化成"节奏表"：

| 时间 | 内容 | 画面变化 |
|---|---|---|
| 0-3s | 钩子 | 近景，直视镜头 |
| 3-15s | 背景 | 近景 + 一句话字幕强调 |
| 15-40s | 主体知识 | 切 2-3 个不同角度避免单调 |
| 40-50s | 总结 | 回到近景 |

**关键**：口播超过 20 秒不换画面，完播率会掉。每 5-8 秒切一次镜头角度或加字幕动效。

## 分镜表的可执行性检查

交付前逐个检查：

- [ ] 每个镜头的景别和拍法都能用手机实现吗？
- [ ] 台词念一遍，是否顺口？有没有需要停顿的地方标注出来？
- [ ] 需要的道具、场地、服装是否在拍摄清单里？
- [ ] 有没有"拍不出来"的抽象描述（如"展现高级感"）？
- [ ] 总时长是否经过 `shot_duration.py` 校验？

## 拍摄清单模板

```
【场地】家里书桌 / 户外咖啡店
【道具】产品 x1、水杯、笔记本
【服装】浅色衬衫（避免纯白，会过曝）
【器材】手机 + 支架 + 领夹麦
【光线】上午 10 点窗边 / 环形灯
【预计】拍摄 40 分钟，剪辑 60 分钟
```
