# 图表类型选择决策树

## 第一步：你要表达什么？

```
你要表达什么？
├─ 比较大小        → 柱状图 / 条形图
├─ 看趋势变化      → 折线图
├─ 看构成占比      → 饼图（≤5 项）/ 堆积柱状图（多项）
├─ 看两个变量关系  → 散点图
├─ 看分布          → 直方图 / 箱线图
└─ 看排名          → 条形图（横向，按值排序）
```

## 各类型的适用与禁忌

| 图表 | 适用 | 禁忌 |
|---|---|---|
| **柱状图** | 分类对比（品类、渠道、部门） | 分类超过 12 个（改条形图） |
| **条形图** | 排名、分类名很长时 | 时间序列（该用折线） |
| **折线图** | 时间趋势 | 分类无顺序时用（如"渠道"） |
| **饼图** | 占比，且 ≤5 项 | 超过 5 项、各项差异很小 |
| **环形图** | 同上，中心可放合计 | 同饼图 |
| **堆积柱状图** | 多项占比随时间变化 | 项数 >5 时看不清 |
| **百分比堆积** | 重结构变化、轻绝对量 | 需要看绝对量时 |
| **散点图** | 相关性（价格 vs 销量） | 样本太少（<20） |
| **直方图** | 连续数值分布 | 分类变量 |
| **箱线图** | 分布对比、找异常值 | 非技术观众看不懂 |
| **瀑布图** | 增减拆解（利润构成） | 项数过多 |
| **组合图** | 两个量纲（金额 + 转化率） | 坐标轴不对齐会误导 |

## 组合图（双轴）的正确用法

场景：一个看绝对量（销售额），一个看比率（转化率）。

```
左轴：销售额（柱状）
右轴：转化率（折线）
```

**必须注意**：
- 两个轴的范围要合理，否则"看起来相关"是假象
- 图例要明确标注哪个对应哪个轴
- 只在**确实需要同时看**时才用，能拆两张就拆

## 美化的六个原则

| 原则 | 做法 |
|---|---|
| 一图一结论 | 标题写成结论（"3 月销售额环比下降 12%"，不是"月度销售额"） |
| 去掉冗余 | 删网格线、删边框、删 3D 效果 |
| 颜色克制 | 最多 3 个主色；重点数据用强调色（红/橙） |
| 标签直读 | 关键数据直接标在图上，不用去数轴 |
| 排序有逻辑 | 按值排序（不是按拼音），时间按时间序 |
| 单位明确 | 金额标"元/万元"，明确是否含税 |

## 中文图表的常见问题

| 问题 | 解法 |
|---|---|
| 中文乱码（方块） | 指定中文字体（Excel 里设"微软雅黑"） |
| 分类名太长被截断 | 改横向条形图，或把长名换行 |
| 数据标签重叠 | 缩小字号、错位标注、或只标最大最小 |
| 千分位与货币符号混用 | 统一格式（建议 `#,##0` 或 `¥#,##0`） |

## 输出给用户的格式

```markdown
【图表 1】各渠道获客量与转化率
- 类型：组合图（柱状 + 折线，双轴）
- X 轴：渠道
- 左轴：获客数（柱状，求和）
- 右轴：转化率（折线，百分比）
- 结论：信息流获客最多但转化最低；私域获客少但转化最高，值得加大投入
- 注意：私域样本量仅 120，转化率波动较大
```

**每个图表建议都要带"结论"和"注意"**——图表本身不会说话，要替用户把话说出来。

## 什么时候不该用图表

- 数据只有 2-3 个数：直接写文字
- 数据差异 <5%：柱子看起来一样高，误导
- 目的是精确读数：用表格
- 一个指标只有一个时间点：用大数字卡片（KPI 卡）
