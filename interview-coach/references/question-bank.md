# 分职能题库（按轮次组织）

> 用法：**先读 JD，再从对应职能的题库里挑题**，并把题目中的 X 替换成 JD 里的具体内容。
> 不要直接把整个题库丢给用户——通用题他自己就能搜到。

## 第一轮 · 专业能力（验证"你会不会"）

### 技术 / 研发
- 讲一个你主导过的技术方案，为什么这么设计？
- 你负责的模块里，最难的技术点是什么？怎么解决的？
- 线上出过事故吗？如何定位、如何复盘？
- 你的技术选型标准是什么？举个例子。
- 最近在学什么技术？为什么学？

### 产品 / 运营
- 讲一个你从 0 到 1 的项目，你的判断依据是什么？
- 这个数据涨了，除了你说的原因，还有别的可能吗？
- 如果预算砍一半，你会怎么调整策略？
- 怎么做用户分层？举一个你实际操作过的例子。
- 你怎么定义一个功能"做成功了"？

### 销售 / 商务
- 讲一次你签下来的大单，关键动作是什么？
- 客户说"太贵了"你怎么应对？
- 怎么开拓一个完全陌生的客户？
- 你丢掉过的最大一单，问题出在哪？
- 你的客户资源是怎么积累和维护的？

### 财务 / 法务 / 人力
- 讲一次你发现的风险点，怎么处理的？
- 处理过最复杂的合规 / 税务 / 劳动争议问题是什么？
- 怎么在效率和合规之间做取舍？
- 你怎么保证数据的准确性？
- 举一个你优化流程的例子。

### 设计 / 内容
- 讲一个你最满意的作品，设计思路是什么？
- 你的方案被否过吗？为什么？后来怎么改的？
- 你怎么理解我们要做的这个品类 / 风格？
- 怎么在有限时间内保证质量？
- 你怎么衡量设计 / 内容的效果？

## 第二轮 · 深挖（验证"你想没想清楚"）

适用于所有职能，核心是**追问三层**：

- 这件事里，**你个人的贡献**占多少？
- 这个数字**怎么算的**？口径是什么？
- 如果**再来一次**，你会怎么改？
- 当时有没有别的方案？为什么没选？
- 如果**资源砍一半**，你会怎么办？
- 这个决策的**前提条件**是什么？前提变了怎么办？
- 有没有**反对意见**？你怎么说服的？

## 第三轮 · 综合（验证"合不合适"）

### 动机类
- 为什么离开上一家公司？
- 为什么选择我们？你了解我们做什么吗？
- 你对我们这个岗位的理解是什么？
- 如果我们和你的预期不符，你会怎么办？

### 规划类
- 未来三年的职业规划？
- 你希望在这个岗位上获得什么？
- 你觉得三年后自己应该到什么位置？

### 自我认知类
- 你最大的优点和缺点？
- 别人怎么评价你？有没有和你的自我认知不一样的？
- 你最近一次被批评是什么事？

### 压力类
- 如果一个项目失败了，责任在你，你怎么处理？
- 你和上级意见不一致时怎么办？
- 你带过最难带的人是什么样的？

### 收尾
- 你期望的薪资是多少？
- 什么时候能到岗？
- 你还有什么想问我们的？

## 弱点针对性提问（必出，至少 2 题）

| 简历特征 | 大概率被追问 |
|---|---|
| 跳槽频繁（3 次以上） | 怎么保证稳定性？ |
| 有空窗期 | 这段时间在做什么？ |
| 职级倒退 | 为什么接受降级？ |
| 跨行业转岗 | 之前的经验怎么迁移？ |
| 项目数据亮眼 | 这数字是你做的还是团队做的？ |
| 前公司知名度低 | 介绍一下你前公司 |
| 技能栏堆砌 | 这个工具你用在哪了？怎么用的？ |
| 经验年限刚够 | 相比更有经验的人，你的优势是什么？ |

## 反问环节题库（给用户的）

**问业务**
- 这个岗位当前最需要解决的问题是什么？
- 团队今年的重点目标是什么？

**问团队**
- 团队目前的构成是怎样的？我加入后会怎么协作？
- 这个岗位的汇报关系是？

**问成长**
- 这个岗位上，做得好的人通常具备什么特质？
- 入职后前三个月，您希望我完成什么？

**不要问**：加班多不多、能不能远程、什么时候涨薪（这些等拿到 offer 再谈，或通过其他渠道了解）。

## 出题纪律

1. **必须贴着 JD**：把 JD 里的关键词嵌进题目
2. **必须贴着简历**：针对简历里的经历与薄弱点出题
3. **难度递进**：一轮基础、二轮深挖、三轮综合
4. **不出套路题**：如"你最大的缺点是什么"这类，最多 1 题
