# 3 秒钩子公式库

前 3 秒决定 70% 的完播率。以下是可直接套用的结构，**把 XX 替换成你的实际内容**。

## 一、悬念式

| 公式 | 示例 |
|---|---|
| 我用了 X 年才发现，XX 一直是错的 | 我用了三年才发现，洗脸一直是错的 |
| 直到我发现这个方法 | 直到我发现了这个存钱方法 |
| 没人告诉过你的 XX | 没人告诉过你的租房真相 |
| 这是我最不想分享的 XX | 这是我最不想分享的选品逻辑 |

## 二、痛点式

| 公式 | 示例 |
|---|---|
| 是不是每次 XX 都让你想砸电脑 | 是不是每次导数据都想砸电脑 |
| 如果你也 XX，这条一定要看完 | 如果你也天天加班，这条一定要看完 |
| 别再为 XX 头疼了 | 别再为报销头疼了 |
| XX 的人最懂这种感觉 | 带娃的人都懂这种感觉 |

## 三、数字式

| 公式 | 示例 |
|---|---|
| 三个方法，让 XX 快一倍 | 三个方法，让做表快一倍 |
| XX 天，我把 XX 从 A 做到了 B | 三十天，我把体脂从 24 降到 18 |
| 花 X 块钱解决了 X 万块的麻烦 | 花 30 块解决了 3 万的麻烦 |
| 试了 X 个，只留下 1 个 | 试了 8 个保温杯，只留下 1 个 |

## 四、反常识式

| 公式 | 示例 |
|---|---|
| 别再 XX 了，这才是正确做法 | 别再背单词了，这才是正确做法 |
| XX 不是越 X 越好 | 运动不是越久越好 |
| 你以为的 XX，其实 XX | 你以为的省钱，其实更费钱 |
| 我劝你别 XX | 我劝你别买这个 |

## 五、身份呼唤式

| 公式 | 示例 |
|---|---|
| 做 XX 的人，这条必须看 | 做电商的，这条必须看 |
| 如果你是 XX，请你停下来 | 如果你是职场新人，请你停下来 |
| XX 党注意了 | 租房党注意了 |
| 只有 XX 才懂 | 只有干过销售才懂 |

## 六、结果前置式（适合带货）

| 公式 | 示例 |
|---|---|
| 这东西让我 XX 从 A 变成 B | 这东西让我早上多睡 20 分钟 |
| 我只做了这一件事，XX 就好了 | 我只做了这一件事，桌面就干净了 |

## 钩子的三个禁忌

1. **不要用疑问句开场**："你知道怎么 XX 吗？" —— 观众会想"不知道，划走"
2. **不要自我介绍**："大家好我是 XX" —— 直接损失 2 秒
3. **不要铺垫**："在讲这个之前，我先说个事" —— 观众没耐心

## 强度自检

写完钩子后问三个问题：

- 这句话**具体**吗？（"效率翻倍"虚，"少加班一小时"实）
- 有**信息差**吗？（观众看到会想"还有这种事？"）
- 是**人话**吗？（念一遍，拗口的改掉）

三问全过，才算合格钩子。
